# Implementation issue template

Read at step 3 of `SKILL.md`, before writing the issues. Fill one copy per resource or data source. The paths follow the root `CLAUDE.md` (*Adding a resource or data source*, *Testing*); when the two disagree, `CLAUDE.md` wins and this template needs fixing.

For a data source, replace `_resource` with `_data_source`, `Resources()` with `DataSources()`, `examples/resources/<name>/resource.tf` with `examples/data-sources/<name>/data_source.tf`, `tests/<name>.tftest.hcl` with `tests/<name>_data_source.tftest.hcl`, and every other `resources/` with `data-sources/`.

## Go tests
Which tests run live depends on the credential (`CLAUDE.md`, *Testing*):
- Standard key: `TestAcc<Name>Resource_basic` creates the object with a minimal config, checks `id` is set, then runs an `ImportState` step; a `CheckDestroy` function verifies the object is gone (or archived) after destroy; gated on `acctest.PreCheck`.
- Admin API or OAuth resource: no live create test, since there is no test organization yet (#58) and OAuth-gated tests are not run. `httptest` tests in `<name>_resource_internal_test.go` (`admintest.NewClient` / `oauthtest.NewClient`) cover create, read, update, delete, import and 404s, and the native test stays at `command = plan`.
- Read-only Admin API data source: a smoke acceptance test gated on `acctest.PreCheckAdmin` that reads `terraform-tests` and asserts presence (`<list>.#`), not values, next to the `httptest` tests.

## Terraform native test (`tests/<name>.tftest.hcl`)
```hcl
test {
  parallel = true
}

run "<name>_resource_creates_<name>" {
  module {
    source = "../examples/resources/<name>"
  }

  assert {
    condition     = output.<name>_id != ""
    error_message = "Expected <name>_id to be non-empty."
  }
}
```
Admin API and OAuth resources plan only (`command = plan`, dummy credential in a `provider "anthropic"` block of the test file) and assert on configured values, since computed ones such as `id` are unknown at plan; self-contained list data sources use `mock_provider "anthropic" {}`. Details in `CLAUDE.md`, *Terraform native tests*.
