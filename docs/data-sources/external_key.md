# anthropic_external_key (Data Source)

Fetches a customer-managed encryption key (CMEK) registered with the organization, by ID, via the Admin API. The ID is `ekey_...`, or the AWS KMS key ARN for organizations on Claude Platform on AWS.

> **API**: `GET /v1/organizations/external_keys/{id}` (Admin API).
> **Auth**: Admin API key (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`).
> **Beta header**: None.
> **Cost**: Free.

## Example Usage

```hcl
# Look up an external key by ID (`ekey_...`, or the KMS key ARN on Claude
# Platform on AWS).
data "anthropic_external_key" "example" {
  id = "ekey_01SDCCSbTxrXDpWc1phhtcfK"
}

output "external_key_provider" {
  description = "KMS provider of the key (`aws`, `gcp` or `azure`)."
  value       = data.anthropic_external_key.example.provider_config.type
}

output "external_key_attachment" {
  description = "Whether a workspace uses the key (`attached` or `unattached`)."
  value       = data.anthropic_external_key.example.attachment
}
```

## Schema

### Required

- `id` (String) Identifier of the external key: a tagged ID prefixed `ekey_`, or the AWS KMS key ARN for organizations on Claude Platform on AWS. This is the value `anthropic_workspace.external_key_id` takes.

### Read-Only

- `attachment` (String) `attached` when at least one workspace, live or archived, encrypts its data with this key; `unattached` otherwise. Only an `unattached` key can have its `geo` and `provider_config` changed, or be deleted.
- `created_at` (String) RFC 3339 timestamp of when the key was registered.
- `display_name` (String) Human-friendly name, or null if none was set.
- `geo` (String) Data residency geo that selects the regional validator for this key.
- `provider_config` (Attributes) Where the key lives in the KMS. `type` tells which of the other attributes are set. (see [below for nested schema](#nestedatt--provider_config))
- `updated_at` (String) RFC 3339 timestamp of the last update.

### Nested Schema for `provider_config`

Read-Only:

- `client_id` (String) `azure` only. Application (client) ID of a single-tenant app registration in your directory. Omit it to use Anthropic's multitenant app.
- `key_name` (String) `gcp`: full resource name of the Cloud KMS key (`projects/.../locations/.../keyRings/.../cryptoKeys/...`). `azure`: name of the key within the vault.
- `kms_arn` (String) `aws` only. Full ARN of the AWS KMS key (at most 2048 characters). On Claude Platform on AWS the key must be a single-Region key in the organization's own AWS account; alias ARNs are rejected.
- `region` (String) `aws` only. AWS region of the key. Derived by the API from `kms_arn` when omitted.
- `tenant_id` (String) `azure` only. Microsoft Entra (Azure AD) tenant ID of the vault.
- `type` (String) KMS provider: `aws`, `gcp` or `azure`.
- `vault_uri` (String) `azure` only. Key Vault data-plane URI: `https://{vault-name}.vault.azure.net` or `https://{hsm-name}.managedhsm.azure.net`.
