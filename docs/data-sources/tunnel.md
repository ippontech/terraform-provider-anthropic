# anthropic_tunnel (Data Source)

Retrieves an MCP tunnel by ID, archived or not (research preview). The tunnel token is not exposed: revealing it is recorded as a compliance event, so only the `anthropic_tunnel` resource does it, once.

> **API**: `GET /v1/tunnels/{tunnel_id}` (Tunnels API).
> **Auth**: OAuth bearer token with the `workspace:manage_tunnels` scope (`auth_token` or `federation`; see `anthropic_tunnel`). API keys are not accepted.
> **Beta header**: `anthropic-beta: mcp-tunnels-2026-06-22`.

## Example Usage

```hcl
data "anthropic_tunnel" "example" {
  id = "tnl_01AAAAAAAAAAAAAAAAAAAAAA"
}

output "tunnel_domain" {
  description = "Domain of the tunnel."
  value       = data.anthropic_tunnel.example.domain
}
```
