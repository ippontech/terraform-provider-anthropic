# anthropic_memories (Data Source)

Lists memories in a memory store (beta). All pages are fetched automatically.

`path_prefix` must be segment-aligned: it has to start and end with `/` (e.g. `/notes/`). `depth = 0` (the default) returns every descendant below `path_prefix` recursively, like `find`. `depth = 1` returns immediate children only; anything deeper rolls up into `prefixes` instead of `memories`, like `ls`.

`content` is `null` on every memory unless `include_content = true`. Setting it populates `content` on each item, but caps the page size the provider fetches per request at 20 (the API's own limit when `view=full`).

> **API**: `GET /v1/memory_stores/{memory_store_id}/memories` (Managed Agents API).
> **Auth**: Standard API key (`api_key` / `ANTHROPIC_API_KEY`).
> **Beta header**: `agent-memory-2026-07-22`.

## Example Usage

```hcl
resource "anthropic_memory_store" "example" {
  name        = "example-memory-store-for-memories"
  description = "Example memory store for the memories list data source."
}

data "anthropic_memories" "all" {
  memory_store_id = anthropic_memory_store.example.id
  depends_on      = [anthropic_memory_store.example]
}

output "memories" {
  description = "List of memories in the store."
  value       = data.anthropic_memories.all.memories
}

output "memory_prefixes" {
  description = "Rolled-up path prefixes (only populated when depth = 1)."
  value       = data.anthropic_memories.all.prefixes
}
```

## Schema

### Required

- `memory_store_id` (String) The ID of the memory store to list memories from (e.g. `memstore_...`).

### Optional

- `depth` (Number) `0` (or omitted) returns all descendants below `path_prefix` (recursive). `1` returns immediate children only; deeper entries roll up into `prefixes`.
- `include_content` (Boolean) When `true`, populates `content` on each memory (capping the page size fetched per request at 20). Defaults to `false`, in which case `content` is null on every item.
- `path_prefix` (String) Optional path prefix filter. Must start with and end with `/` (segment-aligned), e.g. `/notes/`.

### Read-Only

- `memories` (Attributes List) List of memories. (see [below for nested schema](#nestedatt--memories))
- `prefixes` (List of String) Rolled-up path prefixes (only non-empty when `depth = 1`), each including a trailing `/`.
