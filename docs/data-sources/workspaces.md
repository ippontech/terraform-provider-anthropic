# anthropic_workspaces (Data Source)

Lists all Anthropic Workspaces via the Admin API. All pages are fetched automatically.

> **API**: `GET /v1/organizations/workspaces` (Admin API).
> **Auth**: Admin API key (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`): a Claude Console Admin API key, or a personal or service account key not scoped to a workspace. Not available to Claude Enterprise organizations.
> **Beta header**: None.
> **Cost**: Free.

## Example Usage

```hcl
data "anthropic_workspaces" "all" {}

output "workspaces_count" {
  description = "Number of workspaces in the organization."
  value       = length(data.anthropic_workspaces.all.workspaces)
}

# The Default Workspace is listed only on request. The Admin API reports its
# ID in the scope.workspace_id of the API keys bound to it (their workspace_id
# is null).
data "anthropic_workspaces" "with_default" {
  include_default = true
}

# The Default Workspace is the one workspace that only the second list holds.
# Its name cannot tell it apart: another workspace may be named "Default" too.
output "default_workspace_id" {
  description = "ID of the organization's Default Workspace."
  value = one([
    for ws in data.anthropic_workspaces.with_default.workspaces : ws.id
    if !contains(data.anthropic_workspaces.all.workspaces[*].id, ws.id)
  ])
}
```

On Claude Platform on AWS (the provider's `aws` block), workspaces are read through the gateway of the alias's region, and `external_key_id` is an AWS KMS key ARN. A workspace is reachable only through the region it is bound to; whether one region's gateway also returns the workspaces of other regions is not documented. On Claude Models on Google Cloud (`google_cloud`), this data source is not available: the gateway serves no workspace route, and workspace IDs are read in the Claude Console.
