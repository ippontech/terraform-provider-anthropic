# anthropic_rbac_group (Data Source)

Fetches an RBAC group of a Claude Enterprise organization by ID via the Admin API, with the IDs of the custom roles attached to it.

> **API**: `GET /v1/organizations/rbac_groups/{rbac_group_id}` (Admin API, [reference](https://platform.claude.com/docs/en/api/beta/organization/rbac_groups/retrieve)).
> **Availability**: Claude Enterprise organizations only.
> **Auth**: a Claude Enterprise **scoped Admin API key** (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`), created by the primary owner for **all linked organizations**, with the `read:rbac_groups` scope. A Claude Console Admin API key is rejected.
> **Beta header**: None.
> **Cost**: Free.

## Example Usage

```hcl
data "anthropic_rbac_group" "example" {
  id = "rbac_group_01UvWxYzAbCdEfGhIjKlMn"
}

output "rbac_group_name" {
  description = "Name of the RBAC group."
  value       = data.anthropic_rbac_group.example.name
}

output "rbac_group_source_type" {
  description = "How the group was created (`direct` or `scim`)."
  value       = data.anthropic_rbac_group.example.source_type
}

output "rbac_group_role_ids" {
  description = "IDs of the custom roles attached to the group."
  value       = data.anthropic_rbac_group.example.role_ids
}
```
