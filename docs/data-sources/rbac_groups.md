# anthropic_rbac_groups (Data Source)

Lists every RBAC group of a Claude Enterprise organization via the Admin API, groups provisioned by the identity provider (`source_type = "scim"`) included. All pages are fetched automatically.

> **API**: `GET /v1/organizations/rbac_groups` (Admin API, [reference](https://platform.claude.com/docs/en/api/beta/organization/rbac_groups/list)).
> **Availability**: Claude Enterprise organizations only.
> **Auth**: a Claude Enterprise **scoped Admin API key** (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`), created by the primary owner for **all linked organizations**, with the `read:rbac_groups` scope. A Claude Console Admin API key is rejected.
> **Beta header**: None.
> **Cost**: Free.

## Example Usage

```hcl
data "anthropic_rbac_groups" "all" {}

output "rbac_group_ids_by_name" {
  description = "IDs of the RBAC groups, keyed by name (names are not unique, so each name maps to a list)."
  value       = { for g in data.anthropic_rbac_groups.all.rbac_groups : g.name => g.id... }
}

output "scim_rbac_group_ids" {
  description = "IDs of the groups provisioned by the identity provider, which are read-only through the API."
  value       = [for g in data.anthropic_rbac_groups.all.rbac_groups : g.id if g.source_type == "scim"]
}
```
