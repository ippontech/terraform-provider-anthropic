# anthropic_tunnels (Data Source)

Lists the MCP tunnels of the workspace the credential acts on (research preview), newest first. All pages are fetched automatically. Archived tunnels are left out unless `include_archived = true`. Tunnel tokens are not exposed.

> **API**: `GET /v1/tunnels` (Tunnels API).
> **Auth**: OAuth bearer token with the `workspace:manage_tunnels` scope (`auth_token` or `federation`; see `anthropic_tunnel`). API keys are not accepted.
> **Beta header**: `anthropic-beta: mcp-tunnels-2026-06-22`.

## Example Usage

```hcl
data "anthropic_tunnels" "live" {}

data "anthropic_tunnels" "all" {
  include_archived = true
}

output "tunnel_domains" {
  description = "Domains of the workspace's live tunnels, by tunnel ID."
  value       = { for t in data.anthropic_tunnels.live.tunnels : t.id => t.domain }
}

output "archived_tunnel_count" {
  description = "Number of archived tunnels in the workspace."
  value       = length([for t in data.anthropic_tunnels.all.tunnels : t if t.archived_at != null])
}
```
