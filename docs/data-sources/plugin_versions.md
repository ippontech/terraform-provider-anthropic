# anthropic_plugin_versions (Data Source)

Lists the versions of a plugin of a Claude Enterprise organization, through the [Plugins API](https://platform.claude.com/docs/en/manage-claude/plugins-api#list-a-plugins-versions), newest first: the first one is the plugin's `latest_version_id`. Use it to find a version to serve (`served_version_id` on `anthropic_plugin`, through a variable or another configuration, since a data source reading the plugin it pins would be a cycle), or to check the content scan of a stored version that is not served yet.

> **API**: `GET /v1/organizations/plugins/{plugin_id}/versions` (Plugins API).
> **Auth**: Claude Enterprise Admin API key with the `read:plugins` scope (`read:org_audit` and `read:compliance_org_data` work too), in `admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`, created in claude.ai under Organization settings > API. A Claude Console Admin API key does not work.
> **Beta header**: `ce-plugins-2026-09-01`, sent by the provider (the endpoints answer 404 without it).
> **Availability**: beta, Claude Enterprise organizations only, and not organizations with HIPAA readiness enabled.
> **Cost**: Free.

## Example Usage

```hcl
data "anthropic_plugin_versions" "example" {
  plugin_id = "plugin_01Hq3vX8kZcN2mB7pR4tY9wL"
}

output "plugin_version_ids" {
  description = "IDs of the plugin's versions, newest first."
  value       = [for version in data.anthropic_plugin_versions.example.versions : version.id]
}
```
