# anthropic_claude_tag_slack_channel (Data Source)

Reads one Slack channel set up in Claude Tag, through the [Claude Tag API](https://platform.claude.com/docs/en/manage-claude/claude-tag-api#get-a-channel), by its Claude Tag ID (`id`, `slch_...`) or by the IDs Slack shows (`slack.workspace_id` and `slack.channel_id`). By default it holds what the channel stores; with `include_inherited = true`, what applies in it: each setting from the nearest level that sets it (channel, workspace, Slack defaults), the instructions of every level joined broadest first, and the built-in defaults (`enabled` true, `guest_policy` restrict) where no level sets one ([Read what applies in a channel](https://platform.claude.com/docs/en/manage-claude/claude-tag-api#read-what-applies-in-a-channel)). A channel that is not set up is an error.

> **API**: `GET /v1/organizations/claude_tag/slack_channels/{id}`, or `GET /v1/organizations/claude_tag/slack_channels?slack_workspace_id=...&slack_channel_id=...` (Claude Tag API).
> **Auth**: Claude Enterprise scoped Admin API key with the `read:claude_tag` scope (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`), created by the primary owner in claude.ai under Organization settings > API. A Claude Console Admin API key does not work.
> **Beta header**: `experimental-claude-tag-2026-10-21`, sent by the provider (the endpoints answer 404 without it).
> **Availability**: beta, Claude Enterprise organizations with Claude Tag set up and a Slack workspace or Enterprise Grid connected; not Claude Console organizations.
> **Rate limits**: two budgets per organization, shared by all its keys: reads (every `GET`) and changes (every `POST` and `DELETE`). A `429` is retried after its `retry-after`.

## Example Usage

```hcl
# What applies in a channel, wherever each setting is set: the channel, its
# workspace or the organization's Slack defaults.
data "anthropic_claude_tag_slack_channel" "support" {
  slack = {
    workspace_id = "T01ABCD2EFG"
    channel_id   = "C05HJKL6MNP"
  }
  include_inherited = true
}

output "support_channel_enabled" {
  description = "Whether Claude is on in the channel."
  value       = data.anthropic_claude_tag_slack_channel.support.enabled
}

output "support_channel_model" {
  description = "The model new sessions in the channel start on (null: the product's default)."
  value       = data.anthropic_claude_tag_slack_channel.support.model
}
```

## Schema

### Optional

- `id` (String) The channel's Claude Tag ID (prefixed `slch_`). Set it, or `slack`.
- `include_inherited` (Boolean) `true` to read what applies in the channel once every level (channel, workspace, Slack defaults) is taken into account, instead of what the channel stores. Default: `false`. With `true`, `enabled` and `guest_policy` are never null, and a level that cannot be read fails the read (503).
- `slack` (Attributes) Slack's own IDs of the channel, the ones Slack shows (the API's `slack` object). Set it, or `id`. (see [below for nested schema](#nestedatt--slack))

### Read-Only

- `created_at` (String) RFC 3339 timestamp of when the channel was set up.
- `enabled` (Boolean) Whether Claude is on in the channel (claude.ai: **Enable Claude Tag in Slack**). What the channel stores (null when it inherits the setting), or with `include_inherited` what applies in it.
- `environment_id` (String) The cloud environment sessions in the channel run in: an active environment (`env_...`) of the Claude Enterprise organization. Checked when written, not again. A self-hosted runner pool (`ccpool_...`) set in claude.ai is kept, but cannot be set, changed or cleared through the API. Whether an environment created with `anthropic_environment` in a Claude Console workspace is accepted here is not verified. What the channel stores (null when it inherits the setting), or with `include_inherited` what applies in it.
- `guest_policy` (String) What Claude does in a channel while a Slack guest is in it: `allow` (claude.ai: **Full access**), `restrict` (**Restrict**) or `channel_only` (**Channel only**; refused when not available to the organization). What the channel stores (null when it inherits the setting), or with `include_inherited` what applies in it.
- `instructions` (String) Custom instructions Claude reads in every session in the channel. At most 8,192 characters after leading and trailing white space is trimmed; blank text is refused here (omit the attribute to clear the setting). Instructions are additive: the text of every level that sets them is joined, broadest first. What the channel stores (null when it inherits the setting), or with `include_inherited` what applies in it.
- `model` (String) The model new sessions in the channel start on: a model ID the organization can use with Claude Tag, at most 128 characters. Checked when written, not again. What the channel stores (null when it inherits the setting), or with `include_inherited` what applies in it.
- `updated_at` (String) RFC 3339 timestamp of the last change to Claude Tag's record of the channel.
