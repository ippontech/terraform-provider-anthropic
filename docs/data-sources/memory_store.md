# anthropic_memory_store (Data Source)

Retrieves a memory store by ID (beta). Works regardless of whether the store is archived.

> **API**: `GET /v1/memory_stores/{memory_store_id}` (Managed Agents API).
> **Auth**: Standard API key (`api_key` / `ANTHROPIC_API_KEY`).
> **Beta header**: `agent-memory-2026-07-22`.

## Example Usage

```hcl
resource "anthropic_memory_store" "example" {
  name        = "example-memory-store"
  description = "Example memory store for the data source."
}

data "anthropic_memory_store" "example" {
  id = anthropic_memory_store.example.id
}

output "memory_store" {
  description = "Information about the retrieved memory store."
  value       = data.anthropic_memory_store.example
}
```
