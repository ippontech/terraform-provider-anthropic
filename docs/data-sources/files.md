# anthropic_files (Data Source)

Lists files (Files API, generally available). All pages are fetched automatically with cursor pagination. File content is not returned, only metadata.

> **API**: `GET /v1/files` (Files API, generally available, no beta header).
> **Auth**: Standard API key (`api_key` / `ANTHROPIC_API_KEY`).
> **Cost**: Free.

Set `ids` (1 to 100 unique file IDs) to fetch only those files. The API then returns a single page, and IDs that do not resolve to a visible file are silently omitted.

## Example Usage

```hcl
resource "anthropic_file" "example" {
  source_path = "${path.module}/example.txt"
}

# Restrict the listing to specific file IDs. Omit `ids` to list every file in
# the workspace.
data "anthropic_files" "example" {
  ids = [anthropic_file.example.id]
}

output "file_ids" {
  description = "IDs of the listed files."
  value       = data.anthropic_files.example.files[*].id
}
```
