# anthropic_vaults (Data Source)

Lists the vaults of the workspace the API key belongs to (beta), newest first. All pages are fetched automatically. Archived vaults are excluded by default, mirroring the API's default behavior; set `include_archived = true` to include them.

> **API**: `GET /v1/vaults` (Managed Agents API).
> **Auth**: Standard API key (`api_key` / `ANTHROPIC_API_KEY`).
> **Beta header**: `anthropic-beta: managed-agents-2026-04-01`.
> **Cost**: Free.

## Example Usage

```hcl
# Live vaults of the workspace.
data "anthropic_vaults" "live" {}

# Archived vaults included.
data "anthropic_vaults" "all" {
  include_archived = true
}

output "vault_ids" {
  description = "IDs of the live vaults, newest first."
  value       = [for v in data.anthropic_vaults.live.vaults : v.id]
}

output "archived_vault_count" {
  description = "Number of archived vaults in the workspace."
  value       = length([for v in data.anthropic_vaults.all.vaults : v if v.archived_at != null])
}
```
