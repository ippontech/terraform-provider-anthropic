# anthropic_memory (Data Source)

Retrieves a memory by ID from a memory store (beta). Always reads with `view=full`, so `content` is populated.

> **API**: `GET /v1/memory_stores/{memory_store_id}/memories/{memory_id}` (Managed Agents API).
> **Auth**: Standard API key (`api_key` / `ANTHROPIC_API_KEY`).
> **Beta header**: `agent-memory-2026-07-22`.

## Example Usage

```hcl
data "anthropic_memory" "example" {
  memory_store_id = "memstore_01AAAAAAAAAAAAAAAAAAAAAA"
  id              = "mem_01AAAAAAAAAAAAAAAAAAAAAA"
}

output "memory" {
  description = "Information about the retrieved memory."
  value       = data.anthropic_memory.example
}
```

### Required

- `id` (String) The ID of the memory to retrieve (e.g. `mem_...`).
- `memory_store_id` (String) The ID of the memory store the memory belongs to (e.g. `memstore_...`).

### Read-Only

- `content_sha256` (String) Lowercase hex SHA-256 digest of the UTF-8 `content` bytes.
- `content_size_bytes` (Number) Size of `content` in bytes (the UTF-8 plaintext length).
- `created_at` (String) Creation timestamp (RFC 3339).
- `memory_version_id` (String) ID of the `memory_version` representing this memory's current content (a `memver_...` value).
- `path` (String) Hierarchical path of the memory within the store, e.g. `/projects/foo/notes.md`.
- `type` (String) Object type. Always `memory`.
- `updated_at` (String) Last update timestamp (RFC 3339).
