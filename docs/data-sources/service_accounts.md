# anthropic_service_accounts (Data Source)

Lists Workload Identity Federation (WIF) service accounts in the caller's organization (beta). All pages are fetched automatically.

> **API**: `GET /v1/organizations/service_accounts` (beta).
> **Auth**: org:admin OAuth bearer token (`auth_token` / `ANTHROPIC_AUTH_TOKEN`). Admin API keys are not accepted on this endpoint.
> **Beta header**: none required.
> **Cost**: Free.

## Example Usage

```hcl
terraform {
  required_version = ">= 1.0"

  required_providers {
    anthropic = {
      source  = "registry.terraform.io/ippontech/anthropic"
      version = "~> 1.0"
    }
  }
}

# Requires an org:admin OAuth bearer token (auth_token / ANTHROPIC_AUTH_TOKEN);
# Admin API keys are not accepted on this endpoint.
data "anthropic_service_accounts" "example" {}

output "service_accounts" {
  description = "List of Workload Identity Federation service accounts in the organization."
  value       = data.anthropic_service_accounts.example.service_accounts
}
```
