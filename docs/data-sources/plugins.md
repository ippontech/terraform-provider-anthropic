# anthropic_plugins (Data Source)

Lists the plugins of a Claude Enterprise organization, through the [Plugins API](https://platform.claude.com/docs/en/manage-claude/plugins-api#list-plugins): in its marketplaces and in members' personal ones, newest first, with optional filters. Plugins Anthropic publishes and standalone skills are not listed. Each plugin's display fields describe its served version, and a change to `content_scan` alone does not move `updated_at`: a security inventory reads `reach` and `content_scan` on every run.

> **API**: `GET /v1/organizations/plugins` (Plugins API).
> **Auth**: Claude Enterprise Admin API key with the `read:plugins` scope (`read:org_audit` and `read:compliance_org_data` work too), in `admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`, created in claude.ai under Organization settings > API. A Claude Console Admin API key does not work.
> **Beta header**: `ce-plugins-2026-09-01`, sent by the provider (the endpoints answer 404 without it).
> **Availability**: beta, Claude Enterprise organizations only, and not organizations with HIPAA readiness enabled.
> **Cost**: Free.

## Example Usage

```hcl
data "anthropic_plugins" "all" {}

# A security inventory: the plugins whose served version reaches outside the
# member's session (an MCP server or a CLI), or whose content scan raised a
# concern.
output "plugins_to_review" {
  description = "IDs of the plugins to review."
  value = [
    for plugin in data.anthropic_plugins.all.plugins : plugin.id
    if plugin.reach == "remote" || try(contains(["warn", "fail", "unknown"], plugin.content_scan.assessment), false)
  ]
}
```

## Schema

### Optional

- `marketplace_id` (String) Only the plugins of this marketplace (prefixed `marketplace_`). A value that matches nothing gives an empty list.
- `owner_type` (String) Only `organization`-owned plugins, or only `user` (member-owned) ones.
- `owner_user_id` (String) Only the plugins of this member (prefixed `user_`), including after they left the organization. A value that matches nothing gives an empty list.

### Read-Only

- `plugins` (Attributes List) The matching plugins, newest first. (see [below for nested schema](#nestedatt--plugins))

### Nested Schema for `plugins`

Read-Only:

- `components` (Attributes List) The served version's components, null when not recorded. (see [below for nested schema](#nestedatt--plugins--components))
- `content_scan` (Attributes) The served version's content scan, null when it was never scanned. Members are served a version only once its scan is `completed` with `pass` or `warn`. (see [below for nested schema](#nestedatt--plugins--content_scan))
- `created_at` (String) RFC 3339 timestamp of the plugin's creation.
- `created_by` (Attributes) Who created the plugin, null when no creator is recorded (plugins synchronized from Git). (see [below for nested schema](#nestedatt--plugins--created_by))
- `description` (String) The served version's manifest `description`, or null.
- `display_name` (String) The served version's manifest `displayName`, or null.
- `id` (String) The plugin's ID (prefixed `plugin_`).
- `latest_version_id` (String) The newest version, which differs from `served_version_id` while a stored version is not served.
- `manifest_version` (String) The served version's manifest `version`, normalized for display (a leading `v` dropped), or null.
- `marketplace_id` (String) The marketplace the plugin lives in (prefixed `marketplace_`).
- `name` (String) The manifest's `name`: unique within its marketplace, not across the organization.
- `organization_installation_preference` (String) Organization-owned plugins: the organization-wide installation setting, the plugin's own or its marketplace's default. Null for a member-owned plugin.
- `organization_installation_preference_inherited` (Boolean) Whether `organization_installation_preference` comes from the marketplace's default. Null for a member-owned plugin.
- `owner_type` (String) `organization` for a plugin in one of the organization's marketplaces, `user` for one in a member's personal marketplace.
- `owner_user_id` (String) The member who owns the plugin, for `owner_type = "user"`.
- `reach` (String) How far the served version reaches: `remote` (declares an MCP server or a CLI), `privileged` (runs or takes effect on members' machines: hooks, settings, pre-approved tools) or `contained`; null when unclassified.
- `served_version_id` (String) The version members are served (prefixed `pluginver_`).
- `served_version_pinned` (Boolean) Whether the served version is pinned (chosen rather than following the newest version).
- `updated_at` (String) RFC 3339 timestamp of the last served-version change or new version (installation settings, shares and late scan verdicts do not move it).

### Nested Schema for `plugins.content_scan`

Read-Only:

- `assessment` (String) Set once `status` is `completed`: `pass`, `warn`, `fail` or `unknown`.
- `reason` (String) For `warn` and `fail`, the main concern (for example `credential-exposure`), otherwise null.
- `status` (String) `processing` while the scan runs, `completed` when it finished, `errored` when it could not.
