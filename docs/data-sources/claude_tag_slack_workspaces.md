# anthropic_claude_tag_slack_workspaces (Data Source)

Lists the Slack workspaces set up in Claude Tag that the organization owns, newest first, in `slack_workspaces`, through the [Claude Tag API](https://platform.claude.com/docs/en/manage-claude/claude-tag-api#list-workspaces). Each holds its Claude Tag ID (`id`, `slws_...`) and Slack's own ID (`slack.workspace_id`); `slack` also filters the list to one workspace. By default each workspace holds what it stores (`null`: not set on the workspace); with `include_inherited = true`, what applies in it once the organization's Slack defaults are taken into account (see [Stored and inherited values](https://platform.claude.com/docs/en/manage-claude/claude-tag-api#stored-and-inherited-values)), which is what its channels inherit unless they set their own value.

> **API**: `GET /v1/organizations/claude_tag/slack_workspaces` (Claude Tag API).
> **Auth**: Claude Enterprise scoped Admin API key with the `read:claude_tag` scope (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`), created by the primary owner in claude.ai under Organization settings > API. A Claude Console Admin API key does not work.
> **Beta header**: `experimental-claude-tag-2026-10-21`, sent by the provider (the endpoints answer 404 without it).
> **Availability**: beta, Claude Enterprise organizations with Claude Tag set up and a Slack workspace or Enterprise Grid connected; not Claude Console organizations.
> **Rate limits**: two budgets per organization, shared by all its keys: reads (every `GET`) and changes (every `POST` and `DELETE`). A `429` is retried after its `retry-after`.

## Example Usage

```hcl
# What applies in each workspace once the Slack defaults are taken into
# account, to audit it.
data "anthropic_claude_tag_slack_workspaces" "all" {
  include_inherited = true
}

output "workspaces_open_to_guests" {
  description = "Slack IDs of the workspaces whose guest policy resolves to allow."
  value = [
    for workspace in data.anthropic_claude_tag_slack_workspaces.all.slack_workspaces : workspace.slack.workspace_id
    if workspace.guest_policy == "allow"
  ]
}
```
