# anthropic_skill_version (Resource)

Creates and manages a Skill Version on the Anthropic platform (beta). A Skill Version is created by uploading local files to an existing Skill.

## Example Usage

```hcl
terraform {
  required_version = "~> 1.0"

  required_providers {
    anthropic = {
      source  = "registry.terraform.io/ippontech/anthropic"
      version = "~> 0.1.0"
    }
  }
}

resource "anthropic_skill" "example" {
  files = ["${path.module}/SKILL.md"]
}

resource "anthropic_skill_version" "example" {
  skill_id = anthropic_skill.example.id
  files    = ["${path.module}/SKILL.md"]
}

output "skill_version_id" {
  value = anthropic_skill_version.example.id
}

output "version" {
  value = anthropic_skill_version.example.version
}

output "name" {
  value = anthropic_skill_version.example.name
}

output "created_at" {
  value = anthropic_skill_version.example.created_at
}
```

## Schema

### Required

- `files` (List of String) Local file paths to upload for the skill version. Must include a `SKILL.md` file at the root of the directory.
- `skill_id` (String) The ID of the Skill that this version belongs to.

### Read-Only

- `created_at` (String) ISO 8601 timestamp of when the skill version was created.
- `description` (String) Description of the skill version, extracted from the `SKILL.md` file.
- `directory` (String) Top-level directory name extracted from the uploaded files.
- `id` (String) Unique skill version identifier assigned by the API.
- `name` (String) Human-readable name of the skill version, extracted from the `SKILL.md` file.
- `version` (String) Version identifier for the skill, expressed as a Unix epoch timestamp (e.g., `"1759178010641129"`).

## Import

Import an existing skill version using its skill ID and version, separated by a slash:

```shell
terraform import anthropic_skill_version.example <skill_id>/<version>
```
