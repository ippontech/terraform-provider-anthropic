# anthropic_invite (Resource)

Creates and manages an invitation for a user to join the organization via the Admin API.

> **API**: `POST/GET/DELETE /v1/organizations/invites[/{id}]` (Admin API).
> **Auth**: Admin API key (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`).
> **Beta header**: None.
> **Cost**: Free.

> **Note on updates:** There is no update operation on this endpoint: changing `email` or `role` replaces the invite (a new invitation email is sent). The resource remains managed after acceptance or expiration while the API still returns the invite. Deleting this resource cancels the invite when the API permits it.

> **Expired invites:** Terraform does not automatically re-invite a user after the invite expires. To send a new invitation email, explicitly replace the expired invite with `terraform apply -replace=anthropic_invite.example`.

## Example Usage

```hcl
resource "anthropic_invite" "example" {
  email = "new-teammate@example.com"
  role  = "developer"
}

output "invite_id" {
  description = "ID of the invite."
  value       = anthropic_invite.example.id
}

output "invite_email" {
  description = "Email address the invite was sent to."
  value       = anthropic_invite.example.email
  sensitive   = true
}

output "invite_status" {
  description = "Status of the invite."
  value       = anthropic_invite.example.status
}
```

## Schema

### Required

- `email` (String) Email address of the person to invite. Immutable after creation — changing this forces a new resource.
- `role` (String) Organization role to grant once the invite is accepted. The API assigns `user`, `developer`, `billing` or `claude_code_user` in a Claude Console organization, and `user` or `managed` in a Claude Enterprise organization (`managed` needs the `write:rbac_groups` scope on the key, besides `write:members`). `admin` and the Claude Enterprise administrative roles (`owner`, `membership_admin`, `primary_owner`) cannot be assigned through the API: they are granted in the Claude Console or in claude.ai organization settings. Not checked against a list, since the accepted set depends on the organization type; the API rejects an invalid value at apply time. Immutable after creation — changing this forces a new resource.

### Read-Only

- `accepted_at` (String) RFC 3339 timestamp of when the invite was accepted, or empty if it has not been accepted.
- `expires_at` (String) RFC 3339 timestamp of when the invite expires.
- `id` (String) Unique invite identifier assigned by the API.
- `invited_at` (String) RFC 3339 timestamp of when the invite was sent.
- `status` (String) Status of the invite: `pending`, `accepted`, `expired`, or `deleted`.
- `type` (String) Object type. Always `invite`.

## Import

Import an existing invite using its ID:

```shell
terraform import anthropic_invite.example <invite_id>
```
