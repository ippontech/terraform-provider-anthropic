# anthropic_federation_issuer (Resource)

Registers an OIDC identity provider that Anthropic trusts for Workload Identity Federation (beta) in your organization. The `jwks` field controls how the issuer's signing keys are obtained: `discovery` (resolve keys through OIDC discovery), `explicit_url` (fetch keys from a fixed JWKS URL), or `inline` (a static key set).

> **API**: `POST /v1/organizations/federation_issuers`, `GET/POST /v1/organizations/federation_issuers/{id}`, `POST /v1/organizations/federation_issuers/{id}/archive`.
> **Auth**: requires an org:admin OAuth bearer token (`auth_token` / `ANTHROPIC_AUTH_TOKEN`), from `ant auth login --scope org:admin` or a workload identity federation rule. Admin API keys (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`) are **not** accepted on this endpoint.
> **Beta header**: none required.
> **No hard delete**: destroying this resource always archives the issuer. Archiving is rejected with a 400 while a live federation rule still references the issuer — archive or recreate those rules first. Archiving is idempotent.
> **Console-only updates**: updating an issuer that backs a rule with a scope outside `workspace:developer` or `workspace:inference` requires a Console session; an OAuth caller gets an API error.

## Deliberate omissions

Two fields the API exposes on federation issuers are intentionally **not** in this resource's schema:

- **`poll_status`** — a volatile summary of the background JWKS poller (consecutive failures, last/next fetch time) that changes on every poll cycle. Including it in this resource would churn the Terraform plan on every refresh; it belongs in a future `anthropic_federation_issuer` data source instead.
- **`jwks_polling_disabled`** (the update-only toggle to re-enable polling after the system pauses it) — the create API has no equivalent field, so exposing it here would require a create-then-update dance on every apply. This resource only surfaces the resulting `jwks_polling_disabled_at` timestamp (computed); re-enabling polling requires calling the API directly for now.

## Example Usage

```hcl
terraform {
  required_version = "~> 1.0"

  required_providers {
    anthropic = {
      source  = "registry.terraform.io/ippontech/anthropic"
      version = "~> 1.0"
    }
  }
}

# Trust GitHub Actions' OIDC issuer for workload identity federation. The
# issuer URL is publicly reachable over HTTPS, so the default "discovery"
# jwks mode can fetch GitHub's signing keys automatically.
resource "anthropic_federation_issuer" "github_actions" {
  name       = "github-actions"
  issuer_url = "https://token.actions.githubusercontent.com"

  jwks = {
    type = "discovery"
  }

  # GitHub Actions OIDC tokens are short-lived; cap the accepted iat->exp
  # spread accordingly instead of the provider default of 1h.
  max_jwt_lifetime_seconds = 600
}

output "federation_issuer_id" {
  value = anthropic_federation_issuer.github_actions.id
}
```

## Schema

### Required

- `issuer_url` (String) The `iss` claim value to match against incoming JWTs. When `jwks.type` is `discovery` and no `discovery_base` is set, this URL must be publicly reachable over HTTPS so Anthropic can fetch the OIDC discovery document; for `explicit_url` and `inline` modes it is only string-compared to the JWT's `iss` claim and may be an internal URL. Not validated client-side beyond being non-empty.
- `name` (String) Admin-chosen slug identifier. Lowercase letters, digits, and hyphens only. Unique within the organization; a duplicate name returns a 409 from the API.

### Optional

- `check_jti` (Boolean) Whether the jwt-bearer exchange enforces JTI single-use (replay protection) for tokens from this issuer. Applies only to assertions carrying a `jti` claim. Default: `true`.
- `jwks` (Attributes) How the issuer's signing keys are obtained. Defaults to `{type = "discovery"}`. One of three shapes selected by `type`: `discovery` (resolve keys through OIDC discovery), `explicit_url` (fetch keys from a fixed JWKS URL), or `inline` (a static key set). (see [below for nested schema](#nestedatt--jwks))
- `max_jwt_lifetime_seconds` (Number) Maximum allowed `iat`→`exp` spread for assertions from this issuer, in seconds (up to 49h). Assertions must carry both `iat` and `exp`; a missing `iat` is rejected. Default: `3600` (1h).

### Read-Only

- `archived_at` (String) Archive timestamp (RFC 3339). Null if the issuer has not been archived.
- `archived_by_actor_id` (String) Tagged ID (`user_...`/`svac_...`) of the actor that archived this issuer. Null if not archived.
- `created_at` (String) Creation timestamp (RFC 3339).
- `created_by_actor_id` (String) Tagged ID (`user_...`/`svac_...`) of the actor that created this issuer.
- `id` (String) Unique federation issuer identifier (e.g. `fdis_...`).
- `jwks_polling_disabled_at` (String) Set when Anthropic's background JWKS poller has paused polling for this issuer after repeated fetch failures. Null while polling is active. Re-enabling requires the update-only `jwks_polling_disabled: false` toggle on the API, which this resource does not expose (see the provider documentation); use the API directly if this needs unpausing.
- `updated_at` (String) Last update timestamp (RFC 3339).
- `updated_by_actor_id` (String) Tagged ID (`user_...`/`svac_...`) of the actor that last updated this issuer.

### Nested Schema for `jwks`

Required:

- `type` (String) One of `discovery`, `explicit_url`, or `inline`.

Optional:

- `ca_cert_pem` (String) Optional custom CA (PEM) for TLS verification of the JWKS fetch. Only applicable when `type` is `discovery` or `explicit_url`; must be absent for `inline` (no network fetch occurs).
- `discovery_base` (String) Set when the discovery URL differs from `issuer_url`. Only applicable when `type` is `discovery`.
- `keys` (String) JSON array of inline JWK objects. Required when `type` is `inline`; must be absent otherwise.
- `url` (String) JWKS endpoint. Required when `type` is `explicit_url`; must be absent otherwise.
