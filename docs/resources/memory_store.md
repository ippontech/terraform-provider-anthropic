# anthropic_memory_store (Resource)

Creates and manages a memory store: a workspace-scoped collection of text documents that an agent reads and writes across sessions (beta). When attached to a session via `resources[]` at session creation time, it is mounted as a directory inside the session container, and its description is automatically added to the system prompt so the agent knows what it contains. A maximum of 8 stores can be attached per session, typically used to map memory to product structure (one per end-user, per team, per project) or to share reference material across many sessions.

> **API**: `POST/GET/POST/DELETE /v1/memory_stores[/{id}]` (Managed Agents API).
> **Auth**: Standard API key (`api_key` / `ANTHROPIC_API_KEY`).
> **Beta header**: `agent-memory-2026-07-22`.

> ⚠️ Archive notice: archiving is permanent. There is no unarchive operation on the Anthropic API. Once archived, this memory store becomes read-only and cannot be attached to new sessions. Existing sessions that hold an attachment continue to read it. Use `archive_on_destroy = true` to preserve the data on `terraform destroy`; the default `false` permanently deletes the store and all its memories.

## Example Usage

```hcl
# Minimal memory store
resource "anthropic_memory_store" "minimal" {
  name        = "my-memory-store"
  description = "Notes accumulated by the agent across sessions."
}

# Memory store with metadata
resource "anthropic_memory_store" "with_metadata" {
  name        = "memory-store-with-metadata"
  description = "Per-customer memory scoped to the support agent."

  metadata = {
    team        = "support"
    environment = "production"
  }
}

# Memory store archived instead of deleted on terraform destroy
resource "anthropic_memory_store" "preserved" {
  name               = "preserved-memory-store"
  description        = "Retained for audit purposes after the agent is decommissioned."
  archive_on_destroy = true
}

output "memory_store_id" {
  description = "ID of the memory store."
  value       = anthropic_memory_store.minimal.id
}

output "memory_store_created_at" {
  description = "Creation timestamp of the memory store (RFC 3339)."
  value       = anthropic_memory_store.minimal.created_at
}
```

## Schema

### Required

- `description` (String) Free-text description of what the store contains, up to 1024 characters. Included in the agent's system prompt when the store is attached, so word it to be useful to the agent.
- `name` (String) Human-readable name for the store. 1–255 characters. The store's mount-path slug under `/mnt/memory/` is derived from this name.

### Optional

- `archive_on_destroy` (Boolean) If `true`, destroying this resource archives the memory store instead of permanently deleting it. Default: `false`.
- `metadata` (Map of String) Arbitrary key-value tags for your own bookkeeping. Up to 16 pairs; keys 1–64 characters; values up to 512 characters. Not visible to the agent.

### Read-Only

- `archived_at` (String) Archive timestamp (RFC 3339). Null if the store has not been archived.
- `created_at` (String) Creation timestamp (RFC 3339).
- `id` (String) Unique identifier for the memory store assigned by the API (e.g. `memstore_...`).

## Import

Import an existing memory store using its ID:

```shell
terraform import anthropic_memory_store.example <memory_store_id>
```
