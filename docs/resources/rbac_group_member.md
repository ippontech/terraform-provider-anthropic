# anthropic_rbac_group_member (Resource)

Adds a user to an RBAC group of a Claude Enterprise organization via the Admin API, granting them the permissions of the custom roles attached to the group. A member whose organization role is `managed` gets their permissions only through such groups.

> **API**: `GET/POST /v1/organizations/rbac_groups/{rbac_group_id}/members`, `DELETE /v1/organizations/rbac_groups/{rbac_group_id}/members/{user_id}` (Admin API, [reference](https://platform.claude.com/docs/en/api/beta/organization/rbac_groups/members/add)). There is no update endpoint and no single-member read: changing either ID replaces the membership, and a refresh pages the group's member list.
> **Availability**: Claude Enterprise organizations only.
> **Auth**: a Claude Enterprise **scoped Admin API key** (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`), created by the primary owner for **all linked organizations**, with the `read:rbac_groups` and `write:rbac_groups` scopes. A Claude Console Admin API key is rejected.
> **Beta header**: None.
> **Cost**: Free.

> **Note on identity-provider groups:** the membership of a group provisioned by your identity provider (`source_type = "scim"`) cannot be changed through the API while SCIM provisioning is on: adding or removing a member returns 400.

> **Note on drift:** a user removed from the group outside Terraform, or a deleted group, removes this resource from state, so the next apply adds the membership again.

## Example Usage

```hcl
resource "anthropic_rbac_group" "example" {
  name = "Engineering"
}

resource "anthropic_rbac_group_member" "example" {
  rbac_group_id = anthropic_rbac_group.example.id
  user_id       = "user_01AbCdEfGhIjKlMnOpQrSt"
}

output "rbac_group_member_id" {
  description = "Composite ID of the membership (`<rbac_group_id>:<user_id>`)."
  value       = anthropic_rbac_group_member.example.id
}

output "rbac_group_member_email" {
  description = "Email of the user added to the group."
  value       = anthropic_rbac_group_member.example.email
  sensitive   = true
}
```
