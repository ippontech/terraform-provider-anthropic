# anthropic_rbac_group (Resource)

Manages an RBAC group of a Claude Enterprise organization via the Admin API. Groups connect members to custom roles: add members with `anthropic_rbac_group_member`, and attach roles to the group in the [claude.ai admin settings](https://claude.ai/admin-settings), since role attachment is read-only through the API (`role_ids`).

> **API**: `POST/GET/POST/DELETE /v1/organizations/rbac_groups[/{rbac_group_id}]` (Admin API, [reference](https://platform.claude.com/docs/en/api/beta/organization/rbac_groups/create)). Create and update accept only `name`.
> **Availability**: Claude Enterprise organizations only.
> **Auth**: a Claude Enterprise **scoped Admin API key** (`admin_api_key` / `ANTHROPIC_ADMIN_API_KEY`), created by the primary owner for **all linked organizations** (groups are enterprise-wide), with the `read:rbac_groups` and `write:rbac_groups` scopes. A Claude Console Admin API key is rejected.
> **Beta header**: None (`ce-user-management-2026-07-13` is no longer required).
> **Cost**: Free.

> **Note on identity-provider groups:** a group created by this resource always has `source_type = "direct"`. A group provisioned by your identity provider (`source_type = "scim"`) can be imported, but the API rejects renaming or deleting it while SCIM provisioning is on; the provider warns at plan time when a change would do either.

> **Note on deletion:** deleting a group keeps its members in their organizations, but they lose the permissions of the group's roles, and a group spend limit, if any, stops applying to them.

## Example Usage

```hcl
resource "anthropic_rbac_group" "example" {
  name = "Engineering"
}

output "rbac_group_id" {
  description = "ID of the RBAC group."
  value       = anthropic_rbac_group.example.id
}

output "rbac_group_role_ids" {
  description = "IDs of the custom roles attached to the group in the claude.ai admin settings (read-only)."
  value       = anthropic_rbac_group.example.role_ids
}
```

## Schema

### Required

- `name` (String) Name of the RBAC group, 1 to 255 characters. Not unique: two groups can share a name.

### Read-Only

- `created_at` (String) RFC 3339 timestamp of when the group was created.
- `id` (String) ID of the RBAC group (`rbac_group_...`).
- `role_ids` (Set of String) IDs of the custom roles (`rbac_role_...`) attached to the group. Read-only: roles are attached in the claude.ai admin settings. Null when the API reported role data as temporarily unavailable; the next refresh fills it in.
- `source_type` (String) How the group was created: `direct` (in claude.ai or through the API, always the case for a group this resource creates) or `scim` (provisioned by the identity provider). The API rejects renaming or deleting a `scim` group while SCIM provisioning is on.
- `updated_at` (String) RFC 3339 timestamp of when the group was last updated.
