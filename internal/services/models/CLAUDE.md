# Models service notes

Load-bearing details for `internal/services/models/`: the `anthropic_model` / `anthropic_models` data sources (`client.Models`, standard API key). The root `CLAUDE.md` still applies; where a note here says "see above" or "see below" and the target is not in this file, it is a section of the root `CLAUDE.md`. Record new details about this service here, not in the root file.

**Data sources:**
- `anthropic_model` (`internal/services/models/model_data_source.go`) — fetches a single model by ID; both model data sources share their attributes and mapping (`modelAttributes`/`mapModelInfo` in `model_common.go`). Lifecycle fields (SDK v1.79.0+): `lifecycle_stage` is the API's `lifecycle` (`active`/`deprecated`/`retired`), renamed because `lifecycle` is a reserved root attribute name (Terraform meta-argument; the framework rejects the schema, pinned by `TestModelSchemas_validImplementation`), and the plural keeps the same name per entry for consistency; `deprecated_at`, `retires_at` and `line` are null when the API sends null. `capabilities.code_execution` now means "executed code can call the request's other tools"; tool support is `capabilities.server_tools.{code_execution,web_search}`. `capabilities.thinking` (bool, `thinking.supported`) keeps its meaning and is not deprecated; `capabilities.thinking_types` adds the accepted `thinking.type` values (`adaptive`, `between_tools`, `disabled`, `enabled`). `effort.xhigh` and the `supported` flags of the nested capability objects are not exposed. The example's `check` block warns on a non-active model; `tests/model.tftest.hcl` proves it with an aliased `mock_provider` + `override_data` (`expect_failures = [check.model_is_active]`), and the docs show the postcondition variant that fails the plan
- `anthropic_models` (`internal/services/models/models_data_source.go`) — lists models; optional `lifecycle_stages` set (`active`/`deprecated`/`retired`, at least one) sent as the API's `lifecycle[]` filter (sorted); when omitted the API lists `active` and `deprecated` models only, never `retired`
